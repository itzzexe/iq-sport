# مجموعة العراق الرياضية — IQ Sports Group

موقع تفاعلي ثلاثي الأبعاد (WebGL scrollytelling) لمجموعة العراق الرياضية، مبني بالكامل من محتوى ملف الشركة والهوية البصرية الرسمية.

An immersive WebGL scrollytelling site for IQ Sports Group, built entirely from the company profile deck and the official brand guideline.

---

## التشغيل — Running it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm start          # serve the production build
npm run typecheck  # tsc --noEmit
```

Node 20+ required.

## ما الذي بُني من الملفات الأصلية — What came from the source files

كل عنصر بصري في الموقع مستخرج من الملفين المرفقين، لا شيء منه مُعاد رسمه تقريبياً:

| العنصر | المصدر |
|---|---|
| الشعار (أفقي + الأيقونة) | مسارات متجهية مستخرجة من صفحة 03 في دليل الهوية |
| أيقونات الرياضات الستّ | مسارات متجهية من صفحة 08 (منظومة الأيقونات) |
| لوحة الألوان | صفحة 06 — `#000000` `#FFFFFF` `#002173` `#00FF00` `#FD7322` |
| صور المنشآت | صور ملف الشركة (بادل، جيم، مسبح، تنس، كرة قدم، لقطة جوية) |
| صور المدربين | صفحة 05 من ملف الشركة |
| خريطة بغداد | صفحة 03 من ملف الشركة (مقصوصة لإزالة النص المكرر) |
| الأرقام والفروع والنصوص | منقولة حرفياً من ملف الشركة |

**مقاطع الفيديو**: لم يتضمن الملفان أي فيديو. المقاطع الخمسة في `public/video` تم توليدها بـ ffmpeg من صور المنشآت الحقيقية نفسها — حركة كاميرا بطيئة (push-in) بنمط ping‑pong بحيث تدور بلا انقطاع. لاستبدالها بلقطات تصوير حقيقية، ضع الملفات بنفس الأسماء (`<name>.mp4` + `<name>.webm` + `<name>-poster.jpg`) ولا حاجة لتعديل أي كود.

## الخطوط — Typography

دليل الهوية يحدد **Varien** للعناوين و **IBM Plex Sans Arabic** للنصوص و **DIN Arabic Black** للعناوين العربية.

- `IBM Plex Sans Arabic` — مستخدم كما هو (متوفر على Google Fonts).
- `Varien` و `DIN Arabic` خطوط مرخّصة لسطح المكتب، فاستُبدلت مؤقتاً بأقرب بديلين مفتوحين: **Archivo** للعناوين اللاتينية و **Cairo** للعناوين العربية.

لاستخدام الخطوط المرخّصة: ضع ملفات الويب في `src/app/fonts/` واستبدل استدعاءات `next/font/google` في [`src/app/layout.tsx`](src/app/layout.tsx) بـ `next/font/local`. لا شيء آخر يحتاج تعديلاً — المتغيرات `--font-display` و `--font-ar-display` و `--font-body` تغذّي كل شيء.

## صفحات الأقسام — Division pages

لكل قسم صفحة مستقلة على `/divisions/<slug>` بمشهد WebGL خاص به، لا قالب واحد بصورة مختلفة:

| المسار | المشهد |
|---|---|
| `/divisions/padel` | سطح مثقّب من آلاف الكرات المُنسَّخة (instanced) يتموّج ويغور تحت المؤشر — من وجه مضرب البادل |
| `/divisions/gym` | بار حديد بأقراص تتباعد مع التمرير وتعود، ونبض قلب بطيء |
| `/divisions/swimming` | سطح ماء أسود بموجات Gerstner وكاوستيك أخضر، يتموّج عند المؤشر |
| `/divisions/tennis` | ملعب بأبعاده الحقيقية (23.77 × 10.97 م) مرسوم بالضوء، وكرة تعبر الشبكة بذيل |
| `/divisions/football` | كرة مُوجَّهة تتفكك ألواحها مع التمرير وتعود في نهاية الصفحة |
| `/divisions/basketball` | كرة برتقالية (اللون الخامس في الهوية) ترتد بانضغاط واستطالة، وحلقات على الأرض عند كل ارتطام |

كل مشهد في `src/webgl/scenes/` ملف واحد مستقل يقرأ من المخزن المشترك نفسه (`phase.hero`, `phase.page`, `phase.pointer`). الكاميرا موحّدة في `DivisionCanvas.tsx`، وكل مشهد يصف فقط أين يريدها.

زر الحجز في كل صفحة يفتح الرئيسية على `/?activity=<slug>#contact` فيُختار النشاط مسبقاً في النموذج.

## البنية — Architecture

```
src/
  app/          layout (SEO, JSON-LD, fonts), page, globals.css, sitemap, robots
  data/site.ts  كل النصوص والأرقام والفروع والأقسام — مصدر واحد للحقيقة، عربي/إنجليزي
  data/lqip.json صور blur-up مضمّنة في الحزمة (20px WebP لكل صورة)
  lib/          اللغة والاتجاه، Lenis + ScrollTrigger، خطافات، تصنيف أداء الجهاز
  webgl/        مشهد Three.js: الشرائط، الجسيمات، حلقة الأقسام، شيدرات GLSL
  components/   أقسام الصفحة + العناصر المشتركة + سبرايت العلامة
```

### كيف يتحدث الـ DOM مع الـ WebGL

الطبقة ثلاثية الأبعاد **لا تمر عبر حالة React**. `ScrollTrigger` يكتب في كائن قابل للتغيير في [`src/webgl/store.ts`](src/webgl/store.ts)، و `useFrame` يقرأ منه كل إطار. القيم تتغير كل إطار، ودفعها عبر إعادة رسم React سيكلف أكثر من الرسم نفسه.

الترتيب المهم: **GSAP ticker يقود Lenis، و Lenis يقود ScrollTrigger.** ثلاث حلقات `requestAnimationFrame` مستقلة ستنحرف عن بعضها بإطار واحد، ويظهر ذلك كتمزّق بين الكانفاس والنص فوقه.

### تصنيف الأداء

[`src/lib/perf.ts`](src/lib/perf.ts) يحدد `low | mid | high` مرة واحدة عند التحميل بناءً على عدد الأنوية والذاكرة وعرض الشاشة. التصنيف يتحكم في: عدد أجزاء الشريط، عدد الجسيمات، `devicePixelRatio`، و anti-aliasing. الطبقة ثلاثية الأبعاد **لا تُحمَّل إطلاقاً** إذا لم يتوفر WebGL أو إذا طلب المستخدم تقليل الحركة — والموقع يبقى مقروءاً وقابلاً للتصفح بالكامل.

## إمكانية الوصول — Accessibility

- العربية هي اللغة الافتراضية (`dir="rtl"`)، مع تبديل كامل للإنجليزية يقلب الاتجاه — بما في ذلك موضع الشعار ثلاثي الأبعاد في المشهد.
- `prefers-reduced-motion`: يُلغى المشهد ثلاثي الأبعاد، وتتوقف مقاطع الفيديو الخلفية (يبقى الإطار الثابت)، وتظهر كل النصوص فوراً.
- رابط تخطٍّ للمحتوى، حالات تركيز مرئية، ترتيب تنقل منطقي بلوحة المفاتيح، نص بديل لكل صورة، ونقاط الخريطة أزرار حقيقية.
- نموذج الحجز يستخدم `aria-invalid` و `aria-describedby` مع رسائل خطأ نصية.

## نموذج الحجز — The booking form

لا يوجد خادم خلفي. النموذج يركّب الرسالة ويسلّمها لقناة تشغّلها المجموعة فعلاً: واتساب أساساً، والبريد الإلكتروني كبديل. هذا أفضل من نموذج يبدو أنه يعمل بينما تضيع الطلبات في الفراغ.

عند إضافة خادم خلفي، استبدل `handleSubmit` في [`src/components/BookingForm.tsx`](src/components/BookingForm.tsx).

## ما يجب تحديثه قبل النشر — Before going live

القيم التالية عناصر نائبة في [`src/data/site.ts`](src/data/site.ts) و [`src/app/layout.tsx`](src/app/layout.tsx):

- `SITE.url` — النطاق الفعلي (يُستخدم في canonical و sitemap و JSON-LD)
- `CONTACT.phone` — الرقم الحقيقي (يغذّي رابط واتساب مباشرة)
- `CONTACT.email` و `CONTACT.address`
- `CONTACT.socials` — روابط إنستغرام/فيسبوك/واتساب الفعلية
- إحداثيات الفروع على الخريطة (`BRANCHES[].map`) تقريبية بصرياً، لا جغرافية

## النشر — Deployment

مخرَج ثابت بالكامل (كل المسارات prerendered). يعمل على Vercel مباشرة بلا إعداد، أو على أي مستضيف يشغّل `next start`.

```bash
npm run build && npm start
```

الحزمة الأولى ~172 kB JS. Three.js يُحمَّل ديناميكياً بعد أول رسم، فلا يدخل في الحزمة الأولية.
